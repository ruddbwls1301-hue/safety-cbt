# 산업안전기사 CBT 학습 시스템

개인용 React + TypeScript PWA입니다. 학습기록과 문제은행은 브라우저의 IndexedDB에 분리해 저장하며, 로그인·결제·서버 동기화는 MVP에 포함하지 않습니다.

## 구현 계획과 현재 MVP 범위

1. **기반 구조** — Vite, React, TypeScript, 반응형 화면, PWA 앱 셸, 다크모드.
2. **CBT 흐름** — 검수 완료 문제로 과목/기출/오답/북마크 학습, 타이머, 문항 이동, 답안 자동 저장, 채점과 결과 확인.
3. **학습 관리** — 응시 이력, 오답·북마크, 과목별 정답률, JSON 백업/복원.
4. **문제은행** — 직접 입력 및 JSON 가져오기, 원본 과목과 개정 과목 분리, 중복 경고, 검수 대기/완료 상태.
5. **후속 단계** — 제공 PDF/이미지의 OCR 보조 추출과 페이지 미리보기, 다중 문항 검수, 더 세밀한 유사문제 감지 및 클라우드 동기화.

MVP는 1~4단계를 구현합니다. 제공된 PDF는 680쪽 이미지형 문서로 텍스트 레이어가 확인되지 않아, OCR 결과를 검수 없이 문제은행에 자동 등록하지 않습니다. PDF OCR은 후속 단계에 두고, 현재는 문제 입력/JSON 가져오기 후 검수 완료한 문제만 CBT에 노출합니다. 기본 문제 데이터는 비어 있습니다.

## 시험 기준

- 2024~2026: 6과목, 120문항, 180분
- 2027~2029: 5과목, 100문항, 150분
- 합격: 각 과목 40점 이상이며 전체 평균 60점 이상
- 과거 과목명은 `originalSubject`에 보존하고, 개정 기준 재분류는 `currentSubject`에 별도로 기록합니다. 재분류가 비어 있는 문제는 개정 체계 시험에서 제외합니다.

2027~2029 과목명은 국가기술자격법 시행규칙 별표 8의2(2025-09-01 신설)를 기준으로 했습니다. [국가법령정보센터 원문](https://law.go.kr/flDownload.do?bylClsCd=110201&flSeq=157074781&gubun=)

## 로컬 실행

```bash
pnpm install
pnpm dev
```

프로덕션 빌드:

```bash
pnpm build
pnpm preview
```

## JSON 문제 형식

문제은행 화면에서 JSON 파일을 가져오면 모든 문항이 `pending` 검수 상태로 들어갑니다. 필수 필드는 `year`, `round`, `originalSubject`, `prompt`, `choices`, `answer`, `explanation`입니다. `currentSubject`는 개정 기준 재분류가 확인된 경우에만 입력합니다. 각 문항에는 `choices` 4개와 1~4의 `answer`가 필요합니다. 문제은행 내보내기 기능으로 현재 스키마의 예시를 얻을 수 있습니다.

## 데이터 구조

- `questionBank`: 출처·문제·선택지·정답·해설·이미지·원본 과목·개정 과목·검수 상태
- `attempts`: 세션 답안, 북마크, 시작/제출 시각, 채점 결과
- `settings`: 테마와 학습 환경설정

서버가 없어도 설치, 앱 셸 오프라인 로드, 로컬 문제풀이가 가능합니다. 최초 방문 전 문제은행/앱 셸을 내려받아야 하며, 기기간 동기화는 제공하지 않습니다.

## GitHub Pages 배포

`main`에 반영되면 `.github/workflows/pages.yml`이 테스트 후 `pnpm build:pages`로 빌드해 배포합니다. 저장소 Settings → Pages → Source는 "GitHub Actions"여야 합니다.

- 배포 경로는 `VITE_BASE`(예: `/safety-cbt/`)로 지정하며, 지정하지 않으면 도메인 루트(`/`) 기준으로 빌드합니다.
- 이 저장소에는 앱 소스만 둡니다. 문제은행, 교재 이미지, 학습기록, 교정안 파일은 올리지 않습니다.
- 새 주소는 빈 저장소로 시작합니다. 기존 주소의 "기기 이전·백업" 파일을 새 주소에서 가져와 옮깁니다.

## 문항 교정

- 문제은행의 "기호·오탈자 의심만" 필터와 편집기의 기호 입력 도구로 직접 수정할 수 있습니다.
- 문제은행 → "교정안 검토"에서 교정안 JSON(`kind: cbt-corrections`)을 불러와 문항별로 원본 이미지와 대조한 뒤 저장하거나 승인합니다. 불러오기만으로는 데이터가 바뀌지 않습니다.
- 수정한 문항은 같은 ID를 유지하고 검수 대기로 돌아갑니다.
